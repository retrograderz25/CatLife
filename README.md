# CatLife

**Nhóm:** 5  
**Môn học:** Lập trình Hướng Đối Tượng (OOP)

## 1. Giới thiệu dự án 
**CatLife** là một tựa game 2D nhập vai vòng đời giả lập, nơi người chơi hóa thân thành một chú mèo lang thang, tương tác với thế giới xung quanh thông qua các hệ thống nhiệm vụ, thời gian thực (ingame) và hàng loạt các minigame đa dạng. Game sở hữu hệ thống cốt truyện phân nhánh với nhiều Endings tùy thuộc vào kết quả của các sự kiện và chỉ số sinh tồn của người chơi.

## 2. Công nghệ sử dụng
- **Ngôn ngữ lập trình:** Java (Phiên bản >= 8)
- **Game Engine/Framework:** LibGDX (LWJGL3 backend)
- **Quản lý dự án & Build tool:** Gradle
- **Thiết kế giao diện UI:** Scene2D (Gói công cụ UI linh hoạt tích hợp sẵn trong LibGDX)
